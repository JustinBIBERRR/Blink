# Domain docs

Blink uses a single domain context. Before exploring the codebase, read the root [`CONTEXT.md`](../../CONTEXT.md) and the ADRs in [`docs/adr/`](../adr/) that touch the work.

Use the glossary's terms in issues, proposals, and tests. Bring missing or ambiguous terms to `/domain-modeling`. If a proposal conflicts with an existing ADR, name the ADR and explain why the decision may need to be revisited.

Continue if a relevant document is absent. Use `/domain-modeling` to record terms and decisions when they are resolved.
