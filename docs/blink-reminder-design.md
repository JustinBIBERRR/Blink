# Blink 提示设计

默认提示和使用时间规则见 [提示呈现、计时和延后](adr/0001-separate-reminder-timing-and-presentation.md)。

## 已确认

- 同一次提示的渐变效果覆盖所有参与桌面显示的屏幕，并同步呈现。双屏用户看到的是同一次休息提示。
- 可选渐进模糊采用雾气玻璃的视觉效果。
- 延后提示实际显示时开启下一轮计时。离席期间只保留一条待提醒。
- 黑板擦由用户选择启用。每块起雾的屏幕右上角都有固定收纳座，全桌面共用一把黑板擦。点击拾起后可跨屏移动、按住左键连续拖擦多笔，也可用滚轮调整尺寸。持擦时，各屏收纳座显示空槽。点击任一空槽即可手动放回。
- 黑板擦和收纳座沿用[第一版写实斜视角概念稿（下半部分）](design-assets/eraser-original-oblique.png)。保留黑板擦的毛毡底和浅收纳座的材质与厚度。屏幕内的比例与右上角位置见[最终四屏评审稿](design-assets/blink-final-four-panel-review.png)。
- 自定义修饰键是临时拾取的快捷入口，按住拿起，松开放回。持擦期间 Blink 接收用于擦拭的左键和滚轮。归还后恢复普通鼠标操作。
- 擦痕保留到本轮结束，雾气到时自动淡出。每块起雾的屏幕右上角都有关闭按钮，未启用黑板擦时也可用。点任一关闭按钮，或双击停在收纳座里的黑板擦，立即清除所有屏幕的雾。不提供关闭快捷键配置或监听；修饰键仅用于临时持擦。
- 首轮试用时长为边缘提示约 3 秒，雾气模式约 20 秒（含渐入和淡出）。擦拭和缩放不延长提示。
- Windows 报告全屏游戏或演示模式时，自动延后到期提示。窗口化视频会议可从托盘手动暂停。
- 手动暂停到期或用户主动恢复时，从恢复时刻开启一个完整的新间隔。系统自动延后继续保留一条待提醒，从实际显示时开启下一轮。
- 手动暂停的截止时间保存在本地。重启后仍在暂停期内时继续暂停，恢复后重新计时。普通使用计时从启动重新开始。
- 首轮试用以连续 5 分钟无键鼠输入为延后阈值，重新输入后等待 30 秒。阅读等低输入活动仍计入使用时间。
- 提示期间进入上述系统场景、锁屏或睡眠时，立即关闭所有屏幕上的提示并释放鼠标输入，丢弃本轮雾气和擦痕。退出该场景后按计时规则重新判断何时提示。

## 提示动效

[冷凝过程分镜](design-assets/blink-condensation-storyboard.png)展示边缘预告、角落结露、向内扩张和雾气覆盖四个状态。[最终四屏评审稿](design-assets/blink-final-four-panel-review.png)的右上和左下展示雾层材质及擦拭后的清晰区域。

- 默认提示在所有屏幕的外缘同步亮起一次柔和冷光，约 3 秒内渐亮并淡出，整个过程保持正文清晰。
- 雾气模式先播放同样的 3 秒边缘预告。随后四边以不同速度向内凝结，形成柔和、不规则的雾气边界。角落先出现少量细霜和静止水珠。
- 擦拭沿路径一起清除雾、细霜和水珠，露出实时桌面。自然结束时，剩余的雾、细霜和水珠一起淡出。

## 雾气模式的系统通知

- 雾气开始渐入前 3 秒提交「即将开始休息提示」。约 20 秒的雾气时长从渐入开始算。自然淡出完成后立即提交「雾已散去」。同一轮雾气的通知按整次提示发送，多屏共享。
- 用户主动关闭、锁屏、睡眠或系统静默打断时，立即结束本轮，无散雾通知。
- 雾气模式默认启用无声系统通知，用户可单独关闭。关闭通知或系统未显示横幅时，雾气仍沿屏幕边缘渐入并正常淡出。默认短暂边缘提示仅使用视觉效果。
- 系统通知须兼容 Windows 和 macOS，并在两端的打包应用中验收。横幅是否可见取决于系统的通知权限、显示设置和勿扰规则。 [Tauri 通知文档](https://v2.tauri.app/plugin/notification/) · [Windows 通知设置](https://learn.microsoft.com/en-us/windows/apps/develop/settings/settings-common#do-not-disturb) · [macOS 通知设置](https://support.apple.com/guide/mac-help/-mh40583/mac)

## 双平台发布与验收

- Windows 和 macOS 的首个对外版本均交付边缘提示、雾气模式及系统通知、可选黑板擦。开发依次验收计时与边缘提示、雾气与通知、多屏擦拭及退出。
- 项目作者负责在另一台电脑上手动验收 Windows。macOS 由开发侧负责构建、自动化回归与打包应用验证。
- macOS 回归覆盖暂停和重启、锁屏和唤醒、通知启用和关闭、自然淡出和提前结束，以及多屏遮罩和黑板擦归位后的鼠标输入恢复。
