# Blink v1 · 柔和休息提示与雾气玻璃

## Problem Statement

长时间在电脑前写作、阅读或编程的人，容易忘记短暂移开视线。现有 Blink 原型会从屏幕边缘预警，接着用收拢的模糊区域、中央光环和倒计时干预。用户希望日常提醒更安静，能在余光里察觉并继续操作；想要更明显的提醒时，可以主动选择雾气玻璃。两种模式都需要在双屏工作和系统状态变化时表现一致，并且可以可靠地结束。

## Solution

Blink 默认在所有参与桌面显示的屏幕上同步播放约 3 秒的柔和边缘冷光，正文保持清晰。可选的雾气玻璃模式先播放同样的边缘预告，再让半透明水汽沿四边不均匀地向中央凝结。用户可以用写实的黑板擦局部擦开雾气，或从任一屏立即结束整次提示。Windows 和 macOS 首版交付相同的产品功能，并通过系统通知提供可关闭的起雾预告和散雾提示。

## User Stories

1. 作为长时间使用电脑的人，我希望 Blink 定期提示我移开视线，以便在工作时记得给眼睛留出休息时间。
2. 作为正在阅读的人，我希望低输入的阅读计入使用时间，以便不用持续移动鼠标也能收到提醒。
3. 作为离开工位的人，我希望锁屏和睡眠期间停止累积使用时间，以便离开电脑的时间得到正确处理。
4. 作为刚回到工位的人，我希望无输入期间到期的提醒延后到返回缓冲结束，以便先继续手头的事。
5. 作为长时间离席的人，我希望只收到一条延后的提醒，以便回来时不用连着处理多轮提示。
6. 作为有不同工作节奏的人，我希望设置提醒间隔，以便用适合自己的频率收到提示。
7. 作为正在演示或玩全屏游戏的 Windows 用户，我希望系统报告该状态时 Blink 自动延后提示，以便继续当前活动。
8. 作为正在进行窗口化视频会议的人，我希望从托盘或菜单栏手动暂停，以便自己决定什么时候恢复提醒。
9. 作为已经暂停 Blink 的人，我希望重启后继续保留尚未到期的暂停，以便重启不会提前恢复提醒。
10. 作为主动恢复提醒的人，我希望获得一个完整的新间隔，以便有可预期的恢复节奏。
11. 作为使用默认设置的人，我希望边缘亮起并自行淡出，以便保持正文清晰和键鼠操作正常。
12. 作为使用多屏的人，我希望所有屏幕同步提示，以便无论在看哪块屏幕都能察觉。
13. 作为希望有更明显提示的人，我希望选用雾气玻璃，以便更容易意识到该移开视线。
14. 作为启用雾气玻璃的人，我希望看到边缘预告后雾气自然凝结，以便提前感知桌面变化。
15. 作为正在休息的人，我希望雾气会按时自行散去，以便可以直接移开视线并在回来后继续工作。
16. 作为启用了系统通知的人，我希望起雾前和自然散雾后各收到一次无声通知，以便知道这一轮何时开始和结束。
17. 作为多屏用户，我希望每轮只收到一组系统通知，以便同一提醒只出现一次预告和一次结束通知。
18. 作为关闭通知或启用系统勿扰的人，我希望雾气仍能正常呈现和结束，以便继续使用视觉提示。
19. 作为想临时看清一行内容的人，我希望可以启用黑板擦，以便只擦开想看的区域。
20. 作为在任一屏幕上临时看内容的人，我希望从就近的收纳座拿起黑板擦，以便按住左键连续擦并跨屏移动。
21. 作为持续擦拭的人，我希望滚轮能调整擦拭尺寸，以便控制一次露出多大区域。
22. 作为擦过雾气的人，我希望擦痕保持到本轮结束并显示实时桌面，以便读到仍在更新的内容。
23. 作为用完黑板擦的人，我希望点击任一空收纳座归位，以便立即恢复普通鼠标操作。
24. 作为只想短暂擦一下的人，我希望按住自定义修饰键临时拿起黑板擦，以便松开时自动归位。
25. 作为有急事要处理的人，我希望从任一屏点关闭按钮，或双击停在收纳座里的黑板擦，以便立即清除所有屏幕上的雾。
26. 作为关闭黑板擦功能的人，我希望仍然看得到关闭按钮，以便可以独立结束提示。
27. 作为更习惯键盘的人，我希望可以设置可选关闭快捷键，以便从键盘立即结束提示。
28. 作为在提示中锁屏、睡眠或进入静默场景的人，我希望当前提示和输入捕获立即结束，以便回来后仍能正常操作桌面。
29. 作为首次配置的人，我希望用「立即试一次」预览所选提示方式，以便了解实际效果再开始日常使用。
30. 作为在不同电脑间切换的人，我希望 Windows 和 macOS 都提供完整的提醒流程，以便保有相同的使用习惯。

## Implementation Decisions

- 由一个调度器拥有当前提示、暂停和待提醒状态。托盘或菜单栏、设置、快捷键、系统事件和提示窗口通过同一生命周期更新状态。以当轮身份处理延迟到达的窗口事件，已经结束的提示保持结束。
- 使用时间与显示资格分别计算。阅读计时，锁屏和睡眠停计。首轮试用阈值为连续 5 分钟无键鼠输入，重新操作后等 30 秒。到期提示只保留一条，从实际显示时开启下一轮。普通使用计时在重启时重新开始。
- 手动暂停截止时间本地持久化。仍在暂停期内的重启继续暂停，到期或主动恢复后给完整新间隔。Windows 报告全屏游戏或演示模式时延后提示。提示中进入这些场景、锁屏或睡眠时，立即清掉所有屏幕上的提示、丢弃擦痕并释放输入，恢复后按计时规则重新判断。窗口化会议通过手动暂停处理。
- 默认柔和提示是一次约 3 秒的冷光渐亮和渐暗，限制在外缘。雾气玻璃沿用这段预告，随后进入约 20 秒的雾气周期，含渐入和淡出。四边不同速、以柔和不规则的前沿向内凝结，边角出现少量细霜与静止水珠。剩余雾、水珠和细霜在自然结束时一起淡出。
- 每块起雾屏幕右下角有关闭按钮。启用黑板擦时，同一处有采用首版写实斜视角的浅收纳座与毛毡擦。全桌面共用一个黑板擦，持擦时各屏收纳座都显示空槽。单击拾取后可连续擦多笔，点任一空槽放回。长按自定义修饰键可以临时持擦，松开归位。
- 擦拭和缩放所用的左键与滚轮由 Blink 在持擦期间接收。其他普通桌面操作按可穿透行为处理。擦拭一起清除雾、霜和水珠，底下的实时桌面保持可见，擦痕留到本轮结束。滚轮缩放、擦拭与归位均沿用本轮结束时间。
- 点任一关闭按钮、双击归位的黑板擦或使用可选快捷键，均结束整轮并释放鼠标。关闭按钮独立于黑板擦功能。默认界面可通过可见关闭按钮退出。
- 原生无声系统通知仅用于雾气模式，默认启用且可单独关闭。在 3 秒边缘预告开始时提交「即将开始休息提示」，自然淡出完成后提交「雾已散去」。主动关闭或系统打断时直接结束。通知权限或勿扰影响横幅显示，视觉流程独立运行。
- 设置体现所选提示方式、提醒间隔和即时预览。雾气相关开关按模式呈现。休息行为由用户完成，提示播放和结束只代表 Blink 的可观测事件。

## Testing Decisions

- 优先用调度器的公开操作和系统事件作为唯一的共享逻辑测试入口。沿用现有状态转换测试的思路，引入可控时间和平台能力替身，断言对外可见的提醒、通知、暂停状态与输入释放。配置和暂停存储沿用现有存储往返测试的思路。
- 用用例覆盖低输入阅读、锁屏和睡眠停计、5 分钟无输入与 30 秒缓冲、错过多轮时只显示一次、显示后才重置间隔、手动暂停跨重启与恢复后新间隔。
- 用用例覆盖两种提示的顺序、通知开关、自然与提前结束、静默中断，以及结束后迟到事件仍无法显示遮罩。测试关注提交给系统的通知时点和数量。
- 打包应用验收覆盖多屏同步、真实桌面可读和实时更新、写实黑板擦的拾取与多笔跨屏擦拭、滚轮调整、空槽归位、关闭与双击交互、锁屏/唤醒后的输入恢复，以及启用/关闭通知时的实际横幅表现。视觉动效和原生输入用运行中的窗口验收。
- 先在两平台验收计时和边缘提示，再验收雾气与通知，最后验收多屏擦拭与退出。项目作者在另一台电脑上手动验收 Windows，开发侧负责 macOS 构建、自动化回归和打包应用验证。现有 Windows 打包工作流和本地前端构建提供原型基线。

## Out of Scope

- 水珠对桌面实时折射、流动水滴和物理流体模拟。首版用静止水珠、细霜和可擦开的薄雾验证观感。
- 摄像头或生理传感器确认休息、用麦克风猜测用户是否开会、医疗效果评估。
- 统计界面重做。现有提示结束事件只代表一轮提示结束。
- Linux、移动端和其他平台的发布验收。
