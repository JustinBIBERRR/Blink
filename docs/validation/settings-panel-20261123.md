## 用户确认的范围

- 760×700 双栏，较大的字号和留白；左侧间隔/方式，右侧方式说明、关联选项、体验按钮，下方暂停和通用设置。
- 中文标题直接，说明温和，按钮明确动作。
- 两张提醒方式卡片（边缘微光、雾气玻璃）各预留缩略图；正式图片等视觉样式稳定后再生成。
- 自动保存和面板内反馈，移除 Save 按钮与保存系统通知。
- 不做新手引导、教程、步骤弹窗。保留选项含义和权限状态。用户稍后录制 GIF 放 README。
- 默认方式和黑板擦默认状态不变；不恢复关闭快捷键。

## 实现与检查

配置加载完成后才开始自动保存，300ms 合并连续编辑，串行写入。预览及关闭按钮等待最新配置保存成功。失败显示重试入口并阻止误报成功。

macOS 只读取辅助功能状态，不因读取弹授权请求。缺权限时可主动打开系统设置。自动启动目前仅 Windows 有实现；其他平台显示不支持，不提供无效开关。

灰底对照：用户在禁用原生模糊层、保留纹理及擦除后确认可见真实桌面。该机器启用了降低透明度。正式版本检测此设置并省略原生背景模糊，保留透明纹理和擦除；不修改系统偏好。未据此声称普通透明度模式或 Windows 已完成视觉验收。
